# MyResume.AI 📝

Um assistente inteligente construído para resumir textos longos automaticamente utilizando Inteligência Artificial, oferecendo diferentes formatos de saída de acordo com a necessidade do usuário.

## 🚀 O Problema
Muitas vezes, precisamos extrair a essência de artigos, notícias ou documentos longos rapidamente. Este projeto foi desenvolvido para automatizar esse processo, permitindo que o usuário cole um texto e receba um resumo estruturado (como tópicos, parágrafos curtos, etc.) em segundos.

## ⚙️ Funcionalidades
* **Input de Texto Livre:** Área dedicada para colar textos de qualquer tamanho.
* **Seleção de Formato:** Menu suspenso para o usuário escolher como deseja o resumo (Ex: Tópicos, Linguagem Informal, etc.).
* **Processamento via IA:** Integração direta com a API do Google Gemini para gerar resumos de alta qualidade.
* **Feedback Visual:** Indicador de carregamento (loading spinner) enquanto a IA processa a resposta, garantindo uma boa experiência de usuário (UX).

## 🛠️ Tecnologias Utilizadas
* **Front-end / Interface:** [Retool](https://retool.com/) (Plataforma Low-Code).
* **Back-end / IA:** [Google Gemini API](https://deepmind.google/technologies/gemini/).
